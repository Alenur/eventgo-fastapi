# EventGo
EventGo — REST API для сервиса записи на мероприятия и бронирования
билетов. Проект хранит информацию о мероприятиях, пользователях,
категориях билетов и заказах.

API может использоваться как серверная часть сайта или приложения,
в котором посетители выбирают мероприятия и оформляют участие.

## Возможности
- Просмотр мероприятий.
- Просмотр места и времени проведения мероприятия.
- Выбор стандартных или VIP-билетов с указанием цены и доступного количества.
- Регистрация и вход в аккаунт.
- Оформление заказа с расчётом общей стоимости.
- Добавление и редактирование мероприятий и билетов администратором.
